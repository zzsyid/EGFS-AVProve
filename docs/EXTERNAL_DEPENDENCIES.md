# External dependencies

The final carrier runtime requires AudioSeal and VideoSeal from their upstream
repositories. Semantic evidence extraction uses Whisper, SpeechBrain ECAPA,
InsightFace, and CLIP. Optional attack realization uses AniPortrait,
EchoMimicV3, LivePortrait, and kNN-VC through the retained wrappers. Upstream
source code and weights are not redistributed.

Version, checkpoint, and license information should be recorded alongside each
experiment manifest. Do not commit downloaded weights or upstream repositories
to this release package.
